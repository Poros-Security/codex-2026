## PoC
1. Buka akun Facebook yang terlampir di soal dan telusuri postingan yang tersedia.
2. Ikuti clue pada postingan untuk menemukan fragment flag di Google Maps dan artikel.
3. Ikuti link yang menuju Google Forms, kemudian akses arsip keanggotaan di Google Drive.
4. Temukan ID Card si Jendral untuk mendapatkan fragment flag terakhir.
5. Gabungkan seluruh fragment untuk memperoleh flag.
